# 游戏规则

本文档记录所有模拟模式共用的术语、概率与合成规则，作为代码校验基准。

## 符号定义

- `n, 1<=n<=7`：宠物等级。
- `p(n), 1<=n<=6`：等级 `n -> n+1` 的基础合成成功概率。
- `r(n)=5*(n-1), 2<=n<=7`：等级 `n` 的保底阈值。
- `B_n, 2<=n<=7`：等级 `n` 的累计失败计数。保底开启时，立即兑换后保持 `0<=B_n<r(n)`；保底关闭时仅保证 `B_n>=0`，可超过阈值。
- `E_n, 2<=n<=7`：获得一个等级 `n` 宠物所需的期望合成尝试次数（仅由 `p` 决定）。
- `C_n, 2<=n<=7`：获得一个等级 `n` 宠物所需消耗的一级蛋期望数量（受 `p` 和保底机制共同影响）。

## 合成概率

- `p(1)=0.95`
- `p(2)=0.80`
- `p(3)=0.65`
- `p(4)=0.45`
- `p(5)=0.20`
- `p(6)=0.05`

## 宠物合成

对于任意 `1<=n<=6`，一次等级 `n` 合成：

1. 消耗两个等级 `n` 宠物。
2. 以概率 `p(n)` 获得一个等级 `n+1` 宠物。
3. 若失败，返还一个等级 `n` 宠物。
4. 若失败，`B_(n+1) <- B_(n+1) + 1`。
5. 若成功，`B_(n+1)` 保持不变（不清零）。

## 保底兑换

对于任意 `2<=n<=7`，当 `B_n = r(n)` 时：

1. 消耗全部保底进度，`B_n <- 0`。
2. 直接获得一个等级 `n` 宠物。
3. 保底兑换不属于合成，不受概率影响，不消耗任何宠物。

## 保底开关约定

- 默认开启保底兑换。
- 保底开启时，达到阈值立即兑换。
- 保底关闭时，失败计数仍可累计，但不触发兑换。
- 每次合成结束后检查保底；一次检查可分别兑换所有已达到阈值的等级。
