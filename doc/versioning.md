# 版本与兼容性策略

本项目遵循语义化版本。`0.9.x` 是 1.0 前的公开预览系列，用于验证 CLI 和导出格式在实际使用中的稳定性。

## 公开接口

以下内容视为用户可见接口：

- `xyzw-petsim` 的子命令、参数名称、参数含义和退出状态。
- CSV 的列名、列顺序和逐行含义。
- JSON 的字段名、层级结构和字段含义。
- 文档中定义的游戏概率、保底规则和模拟停止条件。
- 默认输出文件名的组成规则。

Rust 模块、函数和结构体目前只供二进制内部使用，不承诺库 API 稳定性。

## 0.9 系列承诺

- `0.9.x` 补丁版本不主动引入破坏性 CLI 或导出格式变更。
- 错误修复可能改变此前不符合规则或文档的数值结果，并会在 changelog 中说明。
- 若 1.0 前必须进行破坏性接口调整，将提升次版本并提供迁移说明。
- 新增可选参数或向 JSON 增加可忽略字段通常视为向后兼容。

## 可复现性范围

固定应用版本、随机种子和实际线程数时，逐次模拟结果应可复现。以下变化可能改变随机数流或结果：

- 更换应用版本或随机数实现。
- 改变线程数或使用自动线程数后在不同机器运行。
- 修改游戏规则、概率或模拟执行顺序。

可复现性用于重跑同一实验，不保证不同版本之间产生完全相同的随机样本矩阵。

## 发布约定

- Git 标签使用 `vMAJOR.MINOR.PATCH`，并与 `Cargo.toml` 版本一致。
- 每个版本在 `CHANGELOG.md` 中记录用户可见变化。
- GitHub Release 提供 Linux 和 Windows 压缩包及 SHA-256 校验文件。
- 1.0 发布前至少完成一次 `0.9.x` 使用周期，确认 CLI 和输出契约无需破坏性调整。
