# stock-drain-simulation

模拟模式：`stock-drain`

实现状态：单次及多线程 Monte Carlo 模拟、终端分位数摘要、CSV/JSON 导出已实现

## 目标

输入初始 1-6 级库存，在每次模拟中尽可能合成到无法继续，统计最终库存分布。

## 输入

- `--stock a1,a2,a3,a4,a5,a6`
- 其中 `a1..a6` 分别表示初始 1..6 级数量。
- 宠物蛋与同级宠物等价（开蛋必得同级宠物）。

## 一次模拟流程（确认版）

- 载入初始库存。
- 按 1->2, 2->3, ..., 6->7 依次处理，每级持续合成到数量不足 2。
- 保底开启时：在过程中尽可能即时使用可兑换保底，避免浪费。
- 记录停止时状态。

由于合成和保底都不会产生更低等级宠物，单次自下而上扫描结束后，1..6 级均不可继续合成。

## 输出矩阵（确认版）

无保底：

- `level1..level7`（7 列）

有保底：

- `level1..level7`（7 列）
- 结束保底进度：`pity2..pity7`（6 列）
- 过程保底使用次数：`pity_used2..pity_used7`（6 列）

模拟服务为每次试验保留一行 `StockDrainTrialResult`。所有终端输出均展示起始资源量。当 `N>1` 时，普通模式展示最终宠物的均值、P5、P10、P20、P30、P40、P50、P60、P70、P80、P90、P95，以及保底进度和使用次数的均值；`N=1` 时展示原始终态。`-q` 模式仅展示最终宠物、保底进度和保底使用次数的均值。

固定种子和固定线程数可复现完整结果矩阵。`--threads 0` 根据可用并行度自动选择线程数，并且不会超过试验数。

## 导出

- CSV 每次试验一行。无保底时包含 `trial` 与 `level1..level7`；有保底时追加 `pity2..pity7` 与 `pity_used2..pity_used7`。
- JSON 的 `config` 记录初始库存、保底开关、种子、完整命令和导出路径。
- JSON 的 `result` 记录试验数、实际线程数，以及每个等级的 `mean/min/p5/p10/p20/p30/p40/p50/p60/p70/p80/p90/p95/max`。
- 有保底时，JSON 的 `result.pity` 额外记录结束进度和使用次数的逐等级统计；无保底时该字段为 `null`。
