# target-cost-simulation

模拟模式：`target-cost`

实现状态：已实现

命令入口：`xyzw-petsim target-cost [options]`。

## 目标

输入目标等级，估计获得一个目标等级宠物所需的一级蛋消耗。

## 一次模拟

- 从空状态开始。
- 持续开一级蛋。
- 在可合成时按低等级优先执行合成。
- 达到目标等级后停止并记录消耗的一级蛋数量。

## 多次模拟

- 重复一次模拟 `trials` 次。
- 输出均值、样本标准差、分位数和均值的 95% 置信区间等统计。
- 置信区间当前使用正态近似：`mean +/- 1.96*std_dev/sqrt(trials)`；`trials=1` 时区间退化为单个观测值。
- `p50` 采用取点法：样本升序排序后计算 `rank=round((n-1)*0.5)`，取该下标对应值。
- 保底关闭时仅执行合成规则；保底开启时同时执行合成与保底兑换规则。
- 固定随机种子和实际线程数时，逐次样本可复现；改变线程数会改变随机数流分配。

## 理论值

### 无保底（精确）

设 `C_n` 为获得一个等级 `n` 宠物所需一级蛋期望数，且 `C_1=1`。对于任意 `1<=k<=6`：

- 一次 `k->k+1` 尝试的期望净消耗为 `1+p(k)`。
- 获得一次成功的期望尝试次数为 `1/p(k)`。
- 层级期望消耗因子为 `M_k=(1+p(k))/p(k)`。

因此：

- `C_n=C_(n-1)*M_(n-1)`
- `C_n=Product_{k=1..n-1} (1+p(k))/p(k)`

### 有保底（近似）

对 `k->k+1` 层级，保底阈值为 `r(k+1)=5*k`。当前实现采用分层 DP 近似：

1. 每层定义状态 `(o,b)`，其中 `o` 是已产出的 `k+1` 数量，`b` 是当前保底计数。
2. 固定目标产出数 `m`，求从 `(0,0)` 到 `o=m` 的期望 `k` 级净消耗。
3. 从顶层向下递推到一级蛋消耗。
4. 非整数产出需求使用相邻整数结果线性插值。

该结果不是全状态精确解，但比简单封闭式近似更贴近蒙特卡洛结果。

## 理论值模式

- `auto`：开启保底时使用 `pity-dp`，关闭保底时使用 `no-pity`。
- `none`：不显示理论值。
- `no-pity`：只显示无保底精确理论值。
- `pity-dp`：只显示有保底近似 DP 理论值。
- `all`：同时显示两者。

## 终端直方图

默认 `--hist-outlier-mode none`：保留全部样本，使用从最小值到最大值的线性等宽分桶。

可选异常值处理：

- `iqr`：移除 `[Q1-k*IQR,Q3+k*IQR]` 之外的样本；常用 `k=1.5` 或 `3.0`。
- `mad`：按 modified z-score 移除超过阈值的样本；推荐阈值 `3.5`。
- `quantile`：移除 `q(alpha)` 与 `q(1-alpha)` 之外的样本。
- `winsor`：将两端样本截帽到分位数边界，不改变样本数。

非 `none` 模式会打印规则、处理前后样本数、两端移除数和截帽数。

## 输出

- 终端摘要与直方图。
- 样本 CSV：每次模拟一个 `eggs` 值，按试验执行顺序编号和输出。
- 摘要 JSON：配置、统计、理论值（按模式）。

## 运行约定

- `trials` 必须大于等于 1。
- `trials=1` 时仍执行统一的 report/export 流程。
- `--quiet` 仅打印摘要，不显示详细统计和直方图。
- `--no-interactive` 不询问 CSV 导出。
